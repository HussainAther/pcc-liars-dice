# Validation Roadmap

## v0.1 — laboratory scaffold

- deterministic heads-up engine
- initial synthetic mechanisms
- provisional observables

## v0.2 — rules, baseline, independent families, balance gate

- freeze the laboratory ruleset
- define a non-PCC Bayesian baseline
- implement two independently structured P/C/Chaos policy families
- alternate opener and balance seat order
- freeze a pairwise competitiveness criterion
- retain the first balance result without tuning

## Next: v0.3 construct-recovery preregistration

Only after the v0.2 balance result is known:

1. define candidate observables without looking at held-out recovery results;
2. define cross-family discriminant-validity criteria;
3. add shuffled-label and baseline falsification checks;
4. use fresh seeds;
5. keep failed axes failed.

No human data are needed for these stages.

## v0.4 — frozen construct recovery

- orthogonal 2 x 2 x 2 P/C/Chaos mixture manipulation with neutral baseline remainder
- label-free candidate observables frozen before fresh evaluation
- cross-family standardized-effect and discriminant-validity gates
- shuffled-label negative controls
- retain partial and failed axes without retuning
