# Cross-Domain PCC Scope

PCC Poker remains the stronger flagship environment because poker naturally combines costly strategic pressure, opponent modeling, and value-preserving stochastic play.

PCC Liar's Dice has a different role: **cross-domain falsification**.

The project asks whether candidate behavioral structure survives a different imperfect-information game with:

- private stochastic information;
- public escalating commitments;
- bluffing;
- repeated opponent interaction;
- a much smaller state/action space than most video games.

A successful Liar's Dice result would strengthen evidence that a phenomenon is not merely poker-specific. A failure would be equally useful: it could reveal that an observable depends on poker mechanics or that a proposed construct is not game-general.

No result in this repository should be described as human evidence without a separate human-data protocol and applicable review.
