# Changelog

## 0.4.0

- Added the first frozen cross-family construct-recovery protocol and factorial mixture harness.
- Added label-free Pressure, Control, and performance-bounded Chaos candidates for held-out recovery.
- Added shuffled-label falsification checks and preserved failed axes by design.

## 0.3.0

- added a frozen fresh-seed decomposition of the repeated Control-over-Chaos imbalance;
- tested three prespecified pathways without changing either policy family: public-history dependence, challenge timing, and stochastic bid plausibility cost;
- found cross-family support for better Control challenge timing and higher Control bid plausibility;
- found history dependence only in Family B, ruling it out as a universal explanation;
- retained the v0.2 balance failure and did not tune policies after the mechanism result;
- expanded the test suite to 21 tests.

## 0.2.0

- froze a simple heads-up Liar's Dice laboratory ruleset;
- added exact information-set bid truth probabilities;
- added a transparent non-PCC Bayesian baseline;
- replaced the single implementation family with two independently structured P/C/Chaos families;
- added public cross-round opponent profiles and alternating opener;
- froze a seat-order-balanced pairwise competitiveness protocol;
- retained the first balance failure without post-result tuning;
- expanded the test suite to 19 tests.
